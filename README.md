HR Analysis Dashboard! 📊
Built an interactive HR Analysis Dashboard using Tableau to track and visualize key workforce metrics:
✅ Attrition Rate (17.6%) & Employee Status (Active/Inactive)
✅ Employee Joining Trend (2018–2026)
✅ Gender & Age Distribution
✅ Average Salary by Department
✅ Department-wise Employee Count
This dashboard provides a clear, data-driven view of workforce composition, compensation trends, and attrition patterns — helping HR teams make smarter decisions on retention, hiring, and planning.
